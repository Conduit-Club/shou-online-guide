# 火车站到校

到校地址为**沪城环路 999 号**。**上海虹桥、上海、上海南和上海西是不同车站**；铁路“上海站”对应的地铁站名是“上海火车站”。

上海虹桥、上海、上海南和上海西站均可通过地铁到 **临港大道**，再乘公交到校。最后一段见[临港大道站到学校](/transport/#临港大道站到学校)。

在龙阳路换乘后，到临港大道还需 **大站车约 43 分钟，普通车约 1 小时**；下地铁后接 1077 路，车上约 **10–20 分钟**，等车和步行另计。[地铁首末班与区间时间](/transport/#16-号线首末班) · [1077 路时间](/transport/#_1077-路首末班与耗时) · [地铁网络图](/transport/#上海地铁网络图)
:::tip[2026 级报到下车点]
[2026 级新生报到指南](https://mp.weixin.qq.com/s/Ij-n7Y8YEUuHfKWTxkcUuA)指定乘 1077 路到 **临港共享区枢纽（近学校六号门）**。下文“沪城环路橄榄路”属于常规到校路线；2026 级新生报到时请采用迎新通知指定下车点，并按现场指引入校。接驳预约和报到流程见[新生指南](/freshman-guide/#到校交通)。本条于 **2026-09-12** 按维护者提供的原文正文核对。
:::

## 上海虹桥站到校

**虹桥火车站 → 2 号线 → 龙阳路 → 16 号线 → 临港大道 → 1077 路 → 沪城环路橄榄路。**

1. 出铁路到达层后，按“地铁”标识进入 **虹桥火车站站**，不用前往机场航站楼。
2. 乘 **2 号线，浦东1号2号航站楼方向**，在 **龙阳路** 下车。
3. 换乘 **16 号线，滴水湖方向**。看清本班车停靠 **临港大道**，不要误乘只到滴水湖的直达车。
4. 在 **临港大道** 下车，乘 1077 路到 **沪城环路橄榄路**，再前往通知指定校门。

虹桥火车站有 2、10、17 号线，进站后跟随 **2 号线**标识。2 号线上的“浦东1号2号航站楼”就是浦东机场方向，途中经过虹桥机场、市中心，再到龙阳路。[线路资料](https://www.shhk.gov.cn/xwzx/002008/002008040/20230401/8d62941b-0931-4bb9-bbc7-ee57b09591f2.html)

## 上海站到校

**上海火车站 → 1 号线 → 人民广场 → 2 号线 → 龙阳路 → 16 号线 → 临港大道 → 1077 路。**

1. 出铁路上海站后，按标识寻找 **地铁 1 号线**，不要只看“地铁”二字就直接进入 3、4 号线。
2. 在 **上海火车站站**乘 **1 号线，莘庄方向**，到 **人民广场** 下车。
3. 换 **2 号线，浦东1号2号航站楼方向**，到 **龙阳路**。
4. 换 **16 号线，滴水湖方向**，到 **临港大道**。
5. 接 **1077 路**，在 **沪城环路橄榄路** 下车后入校。

在人民广场换乘时，跟随 **2 号线**标识走换乘通道，到站台后再确认 **浦东1号2号航站楼方向**；无需出闸重新购票。[学校路线说明](https://yjs.shou.edu.cn/2018/0901/c14023a254566/page.htm)

:::tip[已走到 3、4 号线入口怎么办]
上海站东北出口设有通向地铁 3、4 号线的便捷换乘通道，这不等于直接进入了 1 号线。如果已在这一侧，可查询 **4 号线经世纪大道换 2 号线**的方案，按现场显示选择途经世纪大道的一侧，再到龙阳路换 16 号线。不要为照抄上面的路线，在不熟悉的铁路站区盲目绕行。[便捷换乘通道说明（2024-04-25）](https://jtw.sh.gov.cn/xydt/20240425/f9800b31a2444ffa9d8f41240b9264dc.html)
:::

## 上海南站到校

**上海南站 → 1 号线 → 徐家汇 → 11 号线 → 罗山路 → 16 号线 → 临港大道 → 1077 路。**

1. 在 **上海南站站**乘 **1 号线，富锦路方向**，到 **徐家汇**。
2. 按指引换 **11 号线，迪士尼方向**，到 **罗山路**。徐家汇的换乘需要步行，带行李时留出余量。
3. 换 **16 号线，滴水湖方向**，到 **临港大道**。
4. 接 **1077 路**，到 **沪城环路橄榄路** 后前往校门。

徐家汇和罗山路均为站内换乘。在徐家汇找到 **11 号线迪士尼方向**，到罗山路后改跟 **16 号线**标识，选择 **滴水湖方向**。[学校路线说明](https://yjs.shou.edu.cn/2018/0901/c14023a254566/page.htm)

## 上海西站到校

**上海西站 → 11 号线 → 罗山路 → 16 号线 → 临港大道 → 1077 路。**

按站内指引乘 11 号线至罗山路，换乘停靠临港大道的 16 号线列车，再接 1077 路。2026 级报到指南指定在 **临港共享区枢纽（近六号门）** 下车。来源：[2026 级新生报到指南](https://mp.weixin.qq.com/s/Ij-n7Y8YEUuHfKWTxkcUuA)，2026-09-12 按维护者提供的正文核对。

## 从学校出发赶火车

先用 [12306](https://www.12306.cn/)核对**出发车站、日期与开车时间**，再规划地铁。把出校步行、公交等车、地铁换乘、铁路安检和找检票口都算进去；地铁到站后仍需要时间进入铁路候车区。

夜间抵沪时，查看完整路线能否衔接，而不只是火车站门口还有没有地铁。节假日某条线路延时，并不意味着 16 号线与校门公交也同步延时。实时查询方法见[出发前查什么](/transport/#出发前查什么)。
