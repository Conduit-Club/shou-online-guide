## 临港大道站到学校

:::tip[2026 级报到下车点]
[2026 级新生报到指南](https://mp.weixin.qq.com/s/Ij-n7Y8YEUuHfKWTxkcUuA)指定乘 1077 路到 **临港共享区枢纽（近学校六号门）**。下文“沪城环路橄榄路”属于常规到校路线；2026 级新生报到时请采用迎新通知指定下车点，并按现场指引入校。接驳预约和报到流程见[新生指南](/freshman-guide/#到校交通)。本条于 **2026-09-12** 按维护者提供的原文正文核对。
:::

常规到校可参考以下路线（2026 级报到下车点见上方提示）：**16 号线临港大道站 → 1077 路 → 沪城环路橄榄路站 → 按报到通知前往校门**。这是学校招生办目前公开的公共交通方案。[来源：学校交通指引](https://zsjy.shou.edu.cn/13863/list.htm)

1. 在 **临港大道** 下地铁后，按公交换乘标识寻找 **1077 路**站牌。出站前可向工作人员确认当天上车点，勿仅照旧攻略的出口编号走。
2. 查看站牌，确认这一方向后续停靠 **沪城环路橄榄路**，再上车。不要只看线路数字；同一条路两侧的站点方向不同。
3. 到 **沪城环路橄榄路** 下车，再按[校园地图](/facilities/campus-map.html)和当次报到通知找到允许入校的校门。公交到站不等于已到宿舍或报到点，仍需留出步行时间。

**从学校出发去地铁站**，查询 1077 路往 **临港大道** 方向的上车点。返程站点应重新定位，不要默认就是来时下车的站台。去机场或火车站时，应把等公交、地铁换乘、安检和候车时间一起算入行程。

:::tip[行李较多时]
也可以在临港大道站按现场引导乘出租车，或在网约车平台选择具体校门。下单前核对“上海海洋大学临港校区”，并与同行人确认校门；不要只输入“海洋大学”后直接出发。费用、候车时间和车辆能否入校以当时实际情况为准。
:::

## 16 号线怎么坐 {/* #_16-号线怎么坐 */}

从市区到校常在 **龙阳路** 换乘 16 号线，选择 **滴水湖方向**，在 **临港大道** 下车；从学校进城则乘 **龙阳路方向**。

### 站内换乘与乘车方向

1. **进站**：安检后购票或使用地铁乘车码过闸。单程票可直接选择“临港大道”为终点，站内换乘不用分段购票。
2. **换乘**：在龙阳路跟随 **16 号线**标识，在罗山路则从 **11 号线**转入 **16 号线**。沿换乘通道走，不要跟着“出口”标识出闸。
3. **选车**：看站台屏幕上的方向、发车时间和停站表，确认本班停靠 **临港大道**。**通常情况不要选择直达车**。
4. **下车**：临港大道是滴水湖前一站，下车出闸后寻找 **1077 路**公交站。

16 号线从龙阳路往滴水湖依次经过：

**龙阳路 → 华夏中路 → 罗山路 → 周浦东 → 鹤沙航城 → 航头东 → 新场 → 野生动物园 → 惠南 → 惠南东 → 书院 → 临港大道 → 滴水湖。**

### 普通车、大站车与直达车

| 车种   | 怎么辨认与选择                                             |
| ------ | ---------------------------------------------------------- |
| 普通车 | 每站停靠，到临港大道可直接乘坐                             |
| 大站车 | 停龙阳路、罗山路、新场、惠南、临港大道、滴水湖；到学校可乘 |
| 直达车 | 只停龙阳路、滴水湖两站；到学校应选择其他车次               |

[16 号线停站与快车时刻表](https://service.shmetro.com/hcskb/index.htm?line=16)

### 大站车几点发

| 上车站与方向      | 工作日                                     | 双休日、节假日         |
| ----------------- | ------------------------------------------ | ---------------------- |
| 龙阳路 → 临港大道 | 07:00；10:00–21:00 每小时整点              | 07:00–21:00 每小时整点 |
| 临港大道 → 龙阳路 | 07:03；10:03–17:03、19:03–21:03 每小时一班 | 07:03–21:03 每小时一班 |

例如工作日龙阳路 **10:00** 发车，**10:43** 到临港大道。工作日龙阳路 **08:00、09:00**没有整点大站车，临港大道返程 **18:03**也没有大站车。

:::tip[候车经验]
龙阳路是始发站，列车进站后可能还需要候发。看清屏幕上的开车时间，再决定乘哪一班；携带行李或赶车时，不宜为了某一班快车安排得过紧。
:::

以上为**始发站发车时间**，校门附近的“沪城环路橄榄路”是中途站。时刻来自[巴士派迪 1077 路线路表（2024-04-09 更新）](https://buspedia.top/line/qky8nh)，当天到站可查实时公交。

临港大道到 **沪城环路橄榄路**的车上时间可按 **约 10–20 分钟**安排，等车和下车后走到校门的时间另计。这一段为行程估算。

## 出发前查什么

- **地铁：**在 [Metro 大都会 / 上海地铁官网](https://www.shmetro.com/)查询线路、换乘和出行公告；也可从[市交通委轨道交通入口](https://jtw.sh.gov.cn/csgdjt/index.html)进入首末班车与换乘时刻查询。
- **公交：**用地图或实时公交查询搜索完整站名与线路号，确认上车方向、预计到站、末班车和临时改道；到了站台再核对站牌。
- **新生接站、校车：**只按当年的迎新通知或学校班车通知使用。校内通勤车可能有对象、预约和校历限制，不能当作全年面向所有人的公共接驳车。
- **夜间返校：**分别检查前段线路、16 号线和最后一段公交，前一段还能坐不代表全程还能接上。已错过接驳时，重新规划出租车、网约车或住宿，不要依据旧攻略等待不存在的夜班。
