## 联系前与信息修订

1. 确认校区、学生类别、事项和截止日期，再联系对应部门。
2. 提前准备问题说明；系统故障可保留隐去敏感信息的报错截图，维修可说明楼栋和位置。
3. 号码未接通或入口失效时，查阅部门最新通知，或通过学院辅导员、部门公共邮箱确认。
4. 提交修订时附官方页面、发布日期和核验日期。本页仅收录公开服务联系方式，不收录私人手机号、私人邮箱或内部群二维码。
