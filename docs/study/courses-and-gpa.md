# 大学学什么：课程、学分与 GPA

刚打开培养方案，可能会被“通识必修、专业选修、限选、实践学分”绕晕。它们都算学分，但往往不能互相顶替：专业课修得再多，也可能还缺一门美育课；总学分看着够了，创新创业那一栏却还空着。

所以选课前，先看看自己**哪一类还缺学分**。至于常说的绩点，是另一回事——学分看你完成了多少课程，绩点看你这些课考得怎么样。

下面先聊各专业都会遇到的通识、公共课和创新创业学分，再拿 **2025 级计算机科学与技术专业（计算机科学与技术方向）**举个完整的例子。这里的学分是**整个本科阶段累计的要求**，不是每学年都要再修一份。其他入学年级请找自己的培养方案。

## 不同专业，也有不少共同的课

大学并不是入学后就只学专业课。思政、外语、体育，以及通识教育中的美育、心理健康、创新创业等，都会出现在大家的修读计划里。不过，共同的课程类别不等于全校每个专业的课程名、学分和开课学期完全一致。

### 通识选修：先补缺的类别，再挑喜欢的课

2025 级的通识课程分成海洋环境与生态文明、科学精神与科学技术、政治文明与社会建设、人文经典与艺术审美等模块。**通识选修至少 6 学分**，还要满足“四史类 1 学分”“美育类 2 学分”等要求；各专业可能指定某个模块要选哪些课。

拿计科来说，这 6 学分分成 **1 + 1 + 2 + 2**：

| 模块               | 学分 | 选课时看什么                         |
| ------------------ | ---: | ------------------------------------ |
| 海洋环境与生态文明 |    1 | 课程归属的模块                       |
| 科学精神与科学技术 |    1 | 计科方案注明限选《工程项目管理概论》 |
| 政治文明与社会建设 |    2 | 其中包含四史类必修 1 学分            |
| 人文经典与艺术审美 |    2 | 其中包含美育类必修 2 学分            |

“四史 1”和“美育 2”已经算在对应模块里面，别再往总数上加一次。也别看到课程名字里有“艺术”“创新”就默认它能顶相应学分，选课页面上的**课程类别**更要紧。

通识课可以多问问学长学姐：是写论文、做展示还是考试？有没有小组作业？课程内容合不合自己的兴趣？这些比只问一句“给分高吗”更有用。选课时间和开放课程从[教务处](https://jwc.shou.edu.cn/)当学期通知里查。

### 通识必修：7 学分里还有几项容易漏

2025 级通识必修的“全面发展与创新赋能”模块共 **7 学分**：

| 内容               |  学分 |
| ------------------ | ----: |
| 职业发展与就业指导 |     1 |
| 心理健康教育       |     2 |
| 社会实践           |     2 |
| **创新创业教育**   | **2** |

这几项有的体现在课表上，有的还涉及实践或认定。不要等到毕业审核时才第一次打开这张表。下面单独说说最容易混淆的创新创业学分。

### 公共基础：高数、英语这些课放在哪里

思政、英语、军体课是公共基础的重要部分。数学、物理和计算机类怎么配，则跟专业有关，不能把计科的整张课表当作全校共同课表。

以计科的 **37 学分**为例：思政 **15**、英语 **6**、军体 **6**，再加人工智能导论 **1**、线性代数 B **2**、概率论与数理统计 **3**、大学物理 B **4**。高等数学在这份方案里反而放在后面的“学科基础”模块，找不到时可以直接搜课程名。

数学和英语也不只为了过期末。后面看算法、读英文资料时都会用到，基础课能跟上，专业课会少一些补课的痛苦。

## 创新创业学分：那 2 学分别忘了

2025 级培养方案把**创新创业教育 2 学分**放在通识必修里。对采用这份要求的同学来说，这一栏需要完成，不能靠多修其他类别把它凑过去。它已经包含在通识必修的 7 学分中，不是毕业总学分之外再加 2 学分。

### 怎么拿到这 2 学分

有两条路。教务处的[2026–2027 学年秋季选课通知](https://jwc.shou.edu.cn/2026/0601/c11212a353118/page.htm)明确写了：可以修读“创新创业教育类”课程，也可以参加课外创新活动、学科竞赛等，取得成绩后申请认定。

- **选课修读**：在系统里找课程类别为“创新创业教育类”的课，按要求完成考核。它可以选具体课程，但这一类的学分要求仍要完成。
- **成果认定**：做学校认可的大创、竞赛、科研等，达到认定条件后，提交成果材料申请学分。最后要看教务系统的认定记录，不能只数参加过几次活动。

也就是说，不是所有人都必须去比赛或开公司。你可以通过修课完成要求；已经做过项目、拿过奖的同学，也别忘了看看成果能不能认定。

### 哪些项目、比赛能认学分

下面挑几种常见情况，按 **2026 年 6 月修订的认定标准**列出。这里是认定后的实践课程学分，具体课程归类还要落实到你的培养计划里。

| 做了什么                               | 达到什么条件                         | 可认定学分 |
| -------------------------------------- | ------------------------------------ | ---------: |
| 市级及以上大创项目                     | 参加项目并结题                       |          2 |
| 校级大创或校内其他科创项目             | 参加项目并结题                       |          1 |
| 院级大创项目                           | 参加项目并结题                       |        0.5 |
| 学校认定的国家级 A 类赛事              | 完成赛事，获三等奖及以上的项目组成员 |          3 |
| 学校认定的国家级 B、C 类或省／市级赛事 | 完成赛事，获三等奖及以上的项目组成员 |          2 |
| 学校认定的校级赛事                     | 完成赛事，获三等奖及以上的项目组成员 |          1 |
| 参与教师科研项目                       | 一学期以上，且通过指导教师考核认定   |          1 |

竞赛认不认、算哪一级，看学校当年的赛事清单；清单外的赛事还要另行评议。论文、专利、软著等也有对应标准和署名要求，不能只凭有一张证书就套分。完整表格在[认定通知的附件 1](https://cxw.shou.edu.cn/2026/0603/c1525a353204/page.htm)里。

### 学分替代：多出来的能顶什么

**先看培养计划里需要多少创新创业学分，再看超出的部分能不能替代。** “拿到创新创业学分”和“拿它顶另一门课”是两步，不是认定完就能随便抵掉一门课。

2026 年修订办法第五条允许用**超计划的创新创业教育实践学分**，申请等量替代以下类别：

| 想替代的课程                                             | 办法里的范围                     |
| -------------------------------------------------------- | -------------------------------- |
| 通识教育选修课                                           | 可申请等量替代                   |
| 通识必修里的“全面发展与创新赋能”、公共基础里的“计算机类” | 条文列入不及格课程的替代范围     |
| 不及格的专业选修课                                       | 还须经专业负责人认定             |
| 上面没有列出的课程                                       | 学院审核并提出意见，再报学校审批 |

比如，已经有了**经认定的超计划实践学分**，又缺通识选修学分，就可以向学院询问对应的替代申请。别把“超计划”理解成所有刚拿到的学分，也别默认一份学分既补创新创业的缺口，又能再顶一次其他课。究竟哪门课能替、替完归到哪一栏，办理时拿着自己的培养计划和成绩记录一起核对。

### 去哪里申请，什么时候算到账

认定一般每学期一次，在 **6 月、12 月**办理，具体截止时间看[大学生创新网的通知](https://cxw.shou.edu.cn/)。通常是这几步：

1. 下载当期通知里的申请表，把结题、获奖或科研考核等证明材料准备好，交给自己学院。
2. 学院审核、公示，再报教务处审定和集中公示。
3. 教务处录入学分和成绩后，去系统里核对是否到账、是否归到了需要的模块；要替代其他课程的，再确认替代手续。

证书、结题材料和指导老师的考核意见，拿到时就存好。等到毕业审核前再补材料，会比提前申请麻烦得多。当前办理依据是[2026 年 6 月的新办法](https://cxw.shou.edu.cn/2026/0603/c1525a353204/page.htm)，其第六条已废止 2017 年旧办法，查资料时记得看版本。

### 专业课：不只是学几门编程语言

计科先学怎么写程序，再学怎么组织数据、处理问题，接着看计算机内部如何工作。操作系统、网络、数据库这几门课，讲的正是平时写程序时不一定看得见的那一层。

下面是 **36 学分的学科基础必修课**。学期 1、2 对应大一上下，3、4 对应大二上下，以此类推。

| -------------------- | ---: | ----------------------------- |
| 高等数学（一）       |    4 | 1                             |

| 高等数学（二）       |    4 | 2                             |
| 程序设计基础 II      |    3 | 2                             |

### 专业选修：有些写着“选修”，其实还有限选要求

专业选修至少 **15 学分**，可选内容包括 Python 程序设计、数字图像处理基础、量子人工智能、农业物联网基础等。不过，别忽略课程表最右边的“备注”栏：

| 课程                           | 学分 | 原表备注                   |
| ------------------------------ | ---: | -------------------------- |
| 数学建模                       |    3 | 限选 1                     |
| 高级程序设计                   |    2 | 计科限选 2                 |
| 编译原理                       |    2 | 计科限选 3                 |
| 信息安全概论                   |    3 | 计科限选 4                 |
| 海洋空间信息管理与服务         |    2 | 与下面的课程设计须同时选修 |
| 海洋空间信息管理与服务课程设计 |    1 | 与上面的理论课须同时选修   |

先把自己方向的限选要求看清，再安排其他专业选修。培养方案列的是课程范围，某门课这一学期是否开放，还得看选课系统。

### 实践课：理论过了，课程设计也得做

计科的实践实训一共 **39 学分**：

- **模块一 6 学分**：程序设计基础 I、II 课程设计，大学物理实验，以及数据结构、JAVA 框架、操作系统、数据库、网络等课程设计。
- **本方向模块二 8 学分**：计算机系统基础课程设计、智能辅助编程实践、算法课程设计、中级综合开发实践、生成式 AI 应用架构课程设计、软件工程课程设计、专业大型综合实验。
- **模块三 25 学分**：综合实习 **12**，毕业设计（论文）**13**。

理论课和同名课程设计是两个教学环节，只过了其中一个还不够。短学期也可能有实践安排，提前看看，免得按普通学期结束时间把行程订满。

## 自己的培养方案去哪里找

到教务处下载与你**入学年级**对应的教学一览，在目录里找自己的专业。这里用的是[《2025 级教学一览》](https://jwc.shou.edu.cn/2025/0917/c11235a346103/page.htm)，计科的[学分要求从 PDF 第 427 页开始](https://jwc.shou.edu.cn/_upload/article/files/01/b7/a06d909145ccb158d4ab5533c3ca/afb5e11b-11cd-4ee9-8230-4265b97e50d9.pdf#page=427)，正文页脚是 424。

建议自己存一份，把每类“应修、已修、还差多少”记下来。选下一学期的课时先补缺口，再看先修课和时间冲突，最后挑感兴趣的选修。学长学姐的经验很有用，但别直接拿他们那一届的要求来算自己的毕业学分。

## 成绩、绩点、综测，分别算什么

**成绩**就是一门课的总评，通常由平时和期末等部分组成。算 GPA 时填总评，别只填期末卷面分。“考查课”也有自己的考核要求，并不是选上就有学分。

**单科绩点**是成绩换算出的数值，**GPA**则是按学分加权的平均绩点：每门课先算“学分 × 绩点”，全部加起来，再除以计入的总学分。所以高学分课程对 GPA 的影响更大。

**综测**还可能涉及活动、竞赛等其他表现，按自己的学院和年级办法算。综测加分不能直接加到 GPA 上。

### 先分清海大成绩和 GPA 换算

海大用分段表记绩点：例如 90–100 分是 **4.0**。正式五级制的优秀、良好、中等、及格、不及格，分别对应 **4.0、3.3、2.3、1.0、0**；两级制通过、不通过对应 **3.3、0**。同一课程号多次修读，按规定取最高成绩纳入相应统计范围的 GPA。完整规则见[《本科生学籍管理条例》第二十三、二十五条](https://jwc.shou.edu.cn/2018/0902/c11214a227889/page.htm)。

| 百分制成绩 | 五级制 | 两级制 | 绩点 |
| ---------- | ------ | ------ | ---: |
| 90–100     | 优秀   |        |  4.0 |
| 85–89      |        |        |  3.7 |

| 78–81      |        |        |  3.0 |
| 75–77      |        |        |  2.7 |
| 72–74      | 中等   |        |  2.3 |
| 68–71      |        |        |  2.0 |
| 66–67      |        |        |  1.7 |
| 64–65      |        |        |  1.5 |
| 60–63      | 及格   |        |  1.0 |
| 0–59       | 不及格 | 不通过 |    0 |

GPA = Σ（计入课程的学分 × 单科绩点）÷ Σ（计入课程的学分）

3 学分考 90 分，1 学分考 60 分，结果是 `(3 × 4.0 + 1 × 1.0) ÷ 4 = 3.25`，显示为 **3.2500**。计算时保留精度，最后显示才四舍五入；不是先把分数平均，再套换算表。

挂科的百分制课程记 0 绩点，但学分仍留在分母里。通过／不通过、等级制按上面的对应关系计入 GPA；如果某类课程不在你的统计范围内，可以用“计入 GPA”开关排除。

条例规定同一课程号多次修读时取最高成绩。计算器不根据课程名自动识别重复课程，若有重修记录，请只填应计入的最高成绩，或取消较低成绩行的“计入 GPA”。已有绩点按输入值加权，填之前确认它也是同一种 4.0 制口径。
