# 刷 GPA 实用网站

选课前想看看上过课的同学怎么说，期末想找一份能看懂的笔记，或是某一章没听明白想补课——先从下面这些入口找起。

海大相关站点来自 [Issue #24 及其讨论](https://github.com/Conduit-Club/SHOU-Online-Manual/issues/24)。最近整理：**2026-09-11**；各站核验情况见文末。

## 选课前：看看同学的体验

### 海大选课参考

[打开海大选课参考](https://shou.laixk.com/)

Issue 推荐的第三方匿名选课评价论坛。选课前可以找找对应课程和老师的评价，重点看作业量、课堂形式、考核方式，以及评价是哪一年的。

“给分好不好”很主观，同名课程也可能换老师、换考核。看完评价，再对照自己年级的培养方案和当学期选课通知。还没弄清必修、选修和学分分类的话，先看 [课程、学分与 GPA](/study/courses-and-gpa.html)。

本次访问遇到站点验证页，未能核验论坛内部内容；用途说明依据 Issue 推荐，入口暂保留。

## 期末前：找笔记、做练习

### 海大思政题库

[打开海大思政题库](https://bank.635262140.xyz/newHome)

来自 Issue 推荐的第三方思政练习入口。复习时可以先按老师给的章节范围做题，再把错题对应的概念翻回教材重看。

本次确认了首页名称，尚未逐题核验内容与更新年份。“官网同款题库”没有直接学校来源佐证，因此这里只作为补充练习入口；题目、答案及考试范围还请以任课老师和当学期教学平台为准。

### PeterAlbus 的笔记本

[打开PeterAlbus 的笔记本](https://note.peteralbus.com/)

按科目整理的期末复习笔记，计算机相关课程比较集中。可以先翻目录，找到自己没弄懂的一章再读，不必从头刷完整个站。

常用直达：

- [计算机网络](https://note.peteralbus.com/ComputerNetwork.html)
- [操作系统](https://note.peteralbus.com/ComputerOS.html)
- [数据库](https://note.peteralbus.com/Database.html)
- [软件工程](https://note.peteralbus.com/SoftwareEngineering.html)

首页还有计算机组成原理、算法基础、数学建模和汇编笔记。部分材料来自较早学期，例如计网笔记注明依据 **2021 年秋期末考试大纲**；里面标出的重点不能直接当作今年的考试范围。

### Moear's 主页

[打开Moear's 主页](https://moeary.github.io/)

除了技术折腾记录，也有课程复习文章。首页文章会继续更新，找期末材料可以直接走下面几个入口：

- [软工复习题](https://moeary.github.io/posts/软工复习题/)
- [操作系统复习题](https://moeary.github.io/posts/操作系统复习/)
- [LINUX 操作系统复习](https://moeary.github.io/posts/LINUX操作系统复习/)
- [编译原理复习](https://moeary.github.io/posts/编译原理复习/)

复习题可以拿来试着口述答案，再回头查漏补缺。两位同学的笔记都属于个人整理，使用时对照自己的教材版本、课件和老师划定的范围；遇到疑问，先回教材确认。

## 学期中：没听懂的地方再补一遍

### 中国大学 MOOC

[打开中国大学 MOOC](https://www.icourse163.org/)

想换位老师听同一个知识点，可以用课程名搜索高校课程，再对照目录找对应章节。比如卡在高数的一节内容，不一定要从第一讲重新看起。

### 学堂在线

[打开学堂在线](https://www.xuetangx.com/)

另一个在线课程入口。选课时先看课程大纲、授课语言和开课安排，选一门与当前教材接近的来跟。

这些平台适合补充学习。**自行看完网课，不等于自动获得海大学分**；如果是学校指定的在线课程，仍要按当学期通知完成选课、学习和考核。

## 找教材、参考书和文献

### 上海海洋大学图书馆

[打开上海海洋大学图书馆](https://library.shou.edu.cn/)

找书先试书名、作者或 ISBN；查课程论文资料则可以从图书馆的数据库入口开始。校外访问方式和数据库权限看图书馆最新说明，不同资源的使用条件可能不同。

开始写报告或论文后，需要整理参考文献、读英文或排版，可以接着看 [发论文实用工具](/study/paper-tools.html)。
