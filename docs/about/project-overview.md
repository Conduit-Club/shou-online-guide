# 关于水专手册

水专手册是一个由老师学生共同维护的上海海洋大学校园信息项目，目标是把分散在官网、办事系统和同学经验中的实用信息整理成清晰、可更新的入口。

## 项目状态

目前水专手册还在早期建设之中。当前站点完成了文档框架和构建流程，海大专属内容尚在收集与核验中。

## 如何贡献

- 通过 Issue 报告错误、失效链接或希望新增的栏目。
- 通过 Pull Request 修改页面或新增资料。
- 提交校内信息时，附上官方来源、适用范围和最近核验日期。

涉及安全、医疗、财务或个人隐私的信息，请避免提交敏感数据，并优先引用学校官方公告。
