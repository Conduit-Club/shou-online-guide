# 贡献模板与示例

参考上游手册的行文方式，围绕一个真实问题来写。开头交代读者要解决什么，正文按任务或时间线展开，步骤写到可以照着操作，例外情况、经验提示和参考资料放在后面。复制与你要写的栏目相近的模板，替换所有 `〈尖括号〉` 内容，并在提交前核验来源。

## 通用资料卡

内容短的，用资料卡；步骤多的，按“背景—操作—特殊情况—参考资料”展开。字段放进对应段落，正文仍要把事情讲清楚。

```md
## 〈事项或地点〉

一句话说明它解决什么问题，以及适用的人群。

- **适用范围：** 〈身份、学年或日期〉
- **办理/使用时间：** 〈时间；不确定时写“以来源为准”〉
- **入口或位置：** [〈官方页面〉](URL) / 〈楼宇、楼层〉
- **最近核验：** 〈YYYY-MM-DD〉
- **信息来源：** [〈公告或官网页面〉](URL)

:::warning[经验信息]
这是同学整理的经验，不代表学校承诺；如与官方通知冲突，以官方通知为准。
:::
```

## 校历、服务和学习

校历、选课、培养方案、校园卡、统一身份认证等有正式文件的内容，可以套用这个模板：

```md
## 〈学年/服务名称〉

用于 〈适用对象〉 完成 〈事项〉。

1. 打开 [〈官方入口〉](URL)。
2. 选择 〈菜单或办理事项〉。
3. 按页面提示提交 〈材料〉。

- **适用学年/对象：** 〈范围〉
- **关键日期：** 〈日期；没有官方来源就不要填写〉
- **问题反馈：** 〈官方服务台或部门入口〉
- **最近核验：** 〈YYYY-MM-DD〉
- **来源：** [〈官方通知或帮助页〉](URL)
```

可以这样写：

〉 本流程适用于 `〈20XX—20XX 学年、某类学生〉`。步骤整理自 `〈部门〉` 于 `〈日期〉` 发布的 `〈通知名称〉`；如果系统页面与本文不一致，请以系统和最新通知为准。

## 食堂、设施和生活服务

```md
## 〈地点或服务名称〉

〈地点或服务名称〉 位于 〈楼宇 / 楼层〉，主要提供 〈功能〉。

- **营业/开放时间：** 〈工作日〉；〈周末或节假日〉
- **适用对象：** 〈学生 / 教职工 / 预约用户〉
- **支付、预约或门禁：** 〈已核验的信息〉
- **反馈入口：** [〈官方页面〉](URL)
- **最近核验：** 〈YYYY-MM-DD〉
- **来源：** [〈后勤、场馆或运营方页面〉](URL)
```

价格、窗口、营业时间和门禁都属于易变信息。个人推荐可以写，但要单独标为经验并注明日期。

## 新生指南

```md
## 〈20XX 级新生：〈事项〉

- [ ] 阅读 [〈当年官方通知〉](URL)
- [ ] 确认报到日期和交通入口
- [ ] 准备 〈通知列出的材料〉
- [ ] 激活 〈官方系统名称〉
- [ ] 保存 〈官方咨询入口〉

- **适用对象：** 〈年级、培养层次〉
- **最近核验：** 〈YYYY-MM-DD〉
```

新生材料按年份维护。旧攻略里的日期、费用和入口，不能直接套到新年份。

## 联系、应急和隐私

```md
## 〈部门或应急场景〉

〈部门或应急场景〉 负责处理 〈事项范围〉。

- **官方入口：** [〈部门主页或应急页面〉](URL)
- **位置：** 〈楼宇或具体地点〉
- **公开电话：** 〈只填写官方公布号码〉
- **办公/服务时间：** 〈时间〉
- **最近核验：** 〈YYYY-MM-DD〉
- **来源：** [〈官方联系方式或公告〉](URL)
```

遇到紧急情况，直接联系当地紧急服务，以及学校公开的保卫、医疗入口，不要等本站更新。本项目不收录个人手机号、私人邮箱、密码、验证码、身份证件或内部群二维码。

## 交通和校园周边

```md
## 〈出发地〉 → 〈目的地〉

这条路线用于 〈返校 / 办事 / 前往车站〉。

1. 从 〈校门或站点〉 前往 〈换乘点〉。
2. 乘坐 〈线路/交通方式〉，在 〈站点〉 下车。
3. 步行 〈估算时间〉 到达 〈目的地〉。

- **适用日期：** 〈YYYY-MM-DD 或节假日说明〉
- **费用与时长：** 〈有来源支持的估算〉
- **实时入口：** [〈运营方或地图页面〉](URL)
- **最近核验：** 〈YYYY-MM-DD〉
- **来源：** 〈运营方或学校通知 URL〉
```

路线、时刻、价格和商家状态变化较快。没有来源支持时，不要写“始终”“保证”等表述。

## 媒体、组织和活动

```md
## 〈账号/组织/活动名称〉

〈账号/组织/活动名称〉 主要发布或开展 〈内容或活动方向〉，面向 〈成员范围〉。

- **报名或官方入口：** [〈链接〉](URL)
- **时间：** 〈学年、日期或活动周期〉
- **公开联系方式：** 〈官方账号或部门邮箱〉
- **认证/来源：** 〈校方公告、部门页面或公开名录〉
- **最近核验：** 〈YYYY-MM-DD〉
```

涉及学生个人账号时，先征得本人同意。活动和社团名单会随学年变化，也不要把学生组织的宣传写成学校背书。

## 较长文章的行文模板

```md
# 〈读者会搜索的标题〉

本文面向 〈身份或场景〉，解决 〈具体问题〉。

:::warning[适用范围]
本文信息适用于 〈学年/日期〉。如与学校最新通知不一致，以最新通知为准。
:::

## 背景与准备

在开始前，你需要 〈账号、材料、预约或前置条件〉。

## 〈任务一〉

1. 打开 [〈官方入口〉](URL)。
2. 选择 〈菜单〉，填写 〈材料〉。
3. 完成后确认 〈结果或凭证〉。

:::tip[经验提示]
〈经过核验的经验；注明适用日期，不要写成学校承诺。〉
:::

## 〈任务二或特殊情况〉

如果 〈条件〉，请改为 〈另一条流程〉。

## 参考资料

- [〈官方通知/帮助页〉](URL)（发布于 〈YYYY-MM-DD〉）
```

## 提交前检查

- [ ] 所有尖括号都已替换，没有把示例日期当成事实。
- [ ] 有官方链接、文件或可核验来源，并写了最近核验日期。
- [ ] 写清楚适用对象和有效时间。
- [ ] 没有个人敏感信息、未公开联系方式或无法确认的承诺。
- [ ] 价格、电话、时间和政策等易变信息没有省略日期。
