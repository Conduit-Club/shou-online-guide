# 电子邮件

:::warning[待核验]
学校邮箱的开通方式、登录入口、邮箱格式、密码找回和毕业后的使用规则等待补充。

不要在公开页面提交密码、验证码或个人邮箱登录信息。具体邮箱规则以现代信息与教育技术中心及学校最新通知为准。
:::

:::tip[理论入口]
虽然理论目前可从[学校官网](https://www.shou.edu.cn/)进入。
但是通常情况下，因为邮件系统的奇怪问题，一般无法直接登录进入。必须通过[网上办事系统](https://portal.shou.edu.cn/)登录后的入口进入。
修改密码也是不可行的，且外部POP3 IMAP SMTP等协议也无法正常链接。
:::

电子邮件在很多地方可以用于验证你的学生身份。然而，登录学校电子邮件系统是相对麻烦的。

通常情况下，学生需要通过登录学校[网上办事系统](https://portal.shou.edu.cn/)后，借由网上办事系统的登录状态，从办事系统的邮箱入口进入，才可以正常访问。
