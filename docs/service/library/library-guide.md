# 图书馆服务

:::warning[适用范围与时效]
本文主要适用于上海海洋大学临港校区图文信息中心图书馆。日常开放时间、借阅规则与电子资源授权可能随学期、考试周、寒暑假或法定节假日调整，实际安排请以现场告示和图书馆官方最新通知为准。最近核验日期：2026-09-09。

## 场馆概况与主要分布

上海海洋大学图书馆位于临港校区**图文信息中心 1–6 层**，实行“借、阅、藏、查合一”的服务模式，师生凭本人有效校园卡（一卡通 / 电子校园卡）刷闸机入馆。藏书150万余册。

- **场馆位置：** 临港校区图文信息中心 1–6 层
- **主要借阅室：**
  - **109 室：** 社会科学图书借阅室
  - **202 室：** 文史图书借阅室
  - **203 室：** 自然科学图书借阅室
- **读者证件：** 本人校园一卡通 / 电子校园卡（图书借阅仅限本人使用）
- **官方网站：** [上海海洋大学图书馆](https://library.shou.edu.cn/)

## 图书借还与续借流程

### 1. 查找图书

1. 访问 [上海海洋大学图书馆书目检索系统（OPAC）](https://library.shou.edu.cn/)，输入书名、作者或 ISBN 检索。
2. 记录目标图书的**馆藏地（如 109、202 或 203 室）**以及**索书号**（如 `TP312/123`）。对应关系见排架规则。
3. 前往对应借阅室，按书架侧面的索书号导引牌找到书籍。

:::tip[关于中图法索书号与排架规则]

- **什么是索书号：** 图书馆藏书按照《中国图书馆分类法》（简称“中图法”）进行分类与排架。索书号是图书在书架上的唯一“物理定位码”，通常由“分类号/书次号”（如 `TP312/123`）组成。
- **大类与借阅室分布对应：**
  - **109 室（社会科学图书借阅室）：** 对应中图法 A-H 类（如哲学社会科学、经济 F、政治与法律 D、文化教育 G、历史地理 K 等）；
  - **202 室（文史图书借阅室）：** 对应中图法 I-J 类（文学,艺术）及相关文史专架；
  - **203 室（自然科学图书借阅室）：** 对应中图法 N–Z 类（如数理科学与化学 O、工业技术与计算机 TP、水产与农业科学 S、环境科学 X 等）。
- **找书排架规律：**
  1. 书架遵循**从左至右、自上而下**的顺序排架。
  2. 先比对首字母及分类号（按字母顺序及小数制先后排列，如 `TP311` 在 `TP312` 之前，`TP311.1` 在 `TP311.2` 之前）；
  3. 分类号完全相同时，再比对斜杠 `/` 后面的书次号从小到大寻找。

:::

### 2. 借书办理

- **自助借还机：** 将图书放在自助借还机扫描区，将校园一卡通贴在感应区（或扫描电子校园卡码），屏幕确认书名与册数后即可完成借阅。
- **人工柜台：** 若图书芯片消磁不良、借阅卡消磁或有系统异常，可携带图书与校园卡前往底楼总服务台人工办理。

### 3. 还书与续借

- **还书：** 携带图书在馆内自助借还机刷卡，完成后屏幕显示已还即可离开；也可在底楼总服务台归还。
- **续借：** 图书在未逾期、未被他人预约且满足续借时间要求（借出 60 天后至 120 天内）的前提下，读者可登录图书馆官网“我的图书馆”或“上海海洋大学图书馆”微信服务号在线办理续借（延长借期 60 天，限续借 1 次）。若读者逾期欠款超过 10 元，须先处理欠款方可恢复借阅。

## 图书荐购

当想要借阅某书，但学校图书馆尚未收藏该书时，可通过以下方式向图书馆提出荐购申请：

1. **网上推荐（推荐）：** 访问 [上海海洋大学图书荐购系统](https://findshou.libsp.cn/#/personalExternal/6) 在线提交荐购书目。
2. **微信公众号推荐：** 登录“上海海洋大学图书馆”微信公众号，点击底部菜单“图书荐购”。
3. **现场服务台填单：** 前往图文信息中心底楼大厅总服务台，现场填写《图书推荐单》。
4. **电话或 Email 推荐：**
   - 联系电话：`021-61900207`
   - 联系邮箱：`wangyu@shou.edu.cn`

:::tip[荐购填写建议]
推荐时尽量详细填写相关书目信息（如完整书名、作者/译者、ISBN 书号、出版社、出版时间等），以便采访馆员在订购图书时核对与参考。
购买时间较长，3-4个月。
:::

## 研讨室与阅览室预约

### 研讨室在线预约与使用

1. **预约系统入口：** 打开 [研讨室预约系统](http://yantaoshi.shou.edu.cn/)（需在校园网环境或配合 VPN 访问）。
2. **选择房间与时段：** 登录个人账号后，选择 604、606、607、608 室（即约即用）或 605 室（待审核）；填写研讨主题、人数与使用时段后提交。
3. **刷卡入室：** 预约生效后，在预约时段到达对应研讨室门口，刷预约人的**校园一卡通**解锁门禁入内。使用完毕后请带走个人物品并随手关门。

### 研讨室预约与违约规则

1. **预约范围与时长上限：**
   - **教职工：** 可预约 7 天以内的所有房间，每次使用时间最长 **4 小时**。
   - **学生：** 可预约 2 天以内的部分房间，每次使用时间最长 **2 小时**。
2. **房间数量与预约间隔：** 主预约人每人每次只能预约 1 个房间，不得同时预约多个房间。学生连续预约的间隔时间为 **24 小时**。
3. **改期与取消：** 如会议改期或取消，应提前登录研讨室预约系统进行修改或取消操作，以便调配给其他读者使用。
4. **刷卡签到时限（超时自动取消）：** 超过预约起始时间 **30 分钟**，读者仍未刷卡使用研究间，预约系统将自动取消该预约并**记录一次违规**。
5. **最低刷卡人数要求：** 进室刷卡人数**未达 3 人**，将记主预约人**违规一次**。
6. **违规处罚：** 一学期内，若累计有 **3 次违规记录**，系统将暂停该读者随后 **30 天**的研讨室预约权限。

### 阅览室使用与座位预约守则

- 阅览室为公共自习空间，开放时间为 `08:15 - 22:00`。
- **座位预约入口：** 在“上海海洋大学图书馆”微信公众号底部菜单“座位预约”，或使用“学习通”移动端直接扫描桌面二维码预约座位。
- 离开座位超过规定时间或闭馆离场时，请自觉带走随身贵重物品与书本，杜绝私人物品长期霸座现象。

## 电子资源与校外访问

上海海洋大学订购了中文与外文数字文献资源（中国知网 CNKI、万方、Web of Science、IEEE、Elsevier ScienceDirect 等）。

### 1. 校内直接访问

在接入校园网络（校园 Wi-Fi 或有线网络）的环境下，访问对应学术数据库官网，通常会自动通过学校 IP 段授权，无需个人登录即可直接下载文献全文。

### 2. 校外访问途径（CARSI 与 VPN）

在校外、家中使用个人网络时，推荐以下两种访问方式：

- **CARSI 机构账号认证（推荐）：**
  1. 访问支持 CARSI 的数据库平台（如知网、Web of Science 等）。
  2. 点击页面右上角的“登录” 选择“校外访问”或“机构登录（Shibboleth / CARSI）”。
  3. 在高校列表中搜索并选择 **上海海洋大学**。
  4. 页面跳转至学校统一身份认证平台，输入学工号与密码登录成功后，即可直接免费下载资源。
- **校园 WebVPN 访问：** 通过学校信息中心提供的 VPN 门户登录后，通过内网代理渠道访问图书馆电子资源。
